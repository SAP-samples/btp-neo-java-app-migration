# Custom Domain Setup in the Cloud Foundry Environment
You can configure a custom domain for your application using the SAP Custom Domain service.

If you need to remove an existing custom domain first, see [Remove Custom Domain | SAP Help Portal](https://help.sap.com/docs/btp/sap-btp-neo-environment/configuring-application-urls-remove-custom-domain).

Then, for more information on how to set up your new custom domain, check the [Custom Domain service documentation | SAP Help Portal](https://help.sap.com/docs/custom-domain/custom-domain-service/what-is-custom-domain) on SAP Help Portal.
