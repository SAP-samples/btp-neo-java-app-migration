🚀 SAP BTP Neo Demo Application

Declarative Authentication & Authorization

Welcome!

This is a demonstration application showcasing declarative authentication and authorization on SAP BTP Neo platform.

The application uses Java EE servlet-based architecture with role-based access control (RBAC).

Key Features

🔐 Declarative Security

Security constraints defined in web.xml

👥 Role-Based Access

Admin and User roles with different permissions

🌐 Web UI

Interactive web pages for different user roles

🔌 REST APIs

JSON-based REST endpoints with role protection

📚 About This Demo

  • Platform: SAP BTP Neo
  • Framework: Java EE Servlets
  • Authentication: FORM-based
  • Authorization: Declarative (web.xml)
  • Roles: Admin, User
